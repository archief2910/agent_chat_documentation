title: "Introduction"
description: "How a long-running agent turn works."
---

The backend is not deployed to a public host yet. Every route below is served from `/api/v1` on that backend. While you run it locally, the host is `http://localhost:3001`. After you deploy it, use that deployment's origin with the same paths.

A message does not wait for the model to finish.

1. `POST /api/v1/chat/completions` or `POST /api/v1/chats/{chatId}/messages` validates the caller, saves the user message, and starts one durable run.
2. The response is `202` with `runId`. Poll `GET /api/v1/runs/{runId}` until `status` is `completed`, `failed`, or `cancelled`.
3. Text streams separately from run status. PostgreSQL remains the copy that a reload reads.

A chat can have one active run. A second send returns `409` with that run's id.

Crop Image, GPT Image 2, and Merge Videos run on Magica. The Magica key never leaves the server. The model route is OpenRouter Free (`openrouter/free`) with no paid fallback.
