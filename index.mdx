The public API is versioned at `/api/v1`.

<Note>
  Locally the host is `http://localhost:3001`. In production, use the HTTPS origin of the API. This site is the reference. It is not a second API host.
</Note>

A message does not wait for the model to finish.

<Steps>
  <Step title="Start the turn">
    `POST /api/v1/chat/completions` or `POST /api/v1/chats/{chatId}/messages` checks the caller, saves the user message, and starts one durable run.
  </Step>
  <Step title="Read the run">
    The response is `202` with `runId`. Poll `GET /api/v1/runs/{runId}` until `status` is `completed`, `failed`, or `cancelled`.
  </Step>
  <Step title="Reload from Postgres">
    Text streams on stream id `agent-output`. Run status travels as metadata. PostgreSQL is the copy a reload reads.
  </Step>
</Steps>

A chat can have one active run. A second send returns `409` with that run's id.

Crop Image, GPT Image 2, and Merge Videos run on Magica. The Magica key never leaves the server. The model route is OpenRouter Free (`openrouter/free`) with no paid fallback.
