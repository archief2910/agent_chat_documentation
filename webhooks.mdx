Register an HTTPS URL. On this deployment the URL must use `https`. The response is `201` and includes `secret` once, prefixed with `whsec_`. Store it. `GET /api/v1/webhooks` does not return it again.

<ParamField body="url" type="string" required>
  HTTPS endpoint that accepts `POST`.
</ParamField>

<RequestExample>

```bash
curl -X POST https://agent-chat-backend-production.up.railway.app/api/v1/webhooks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/hooks/agent-chat"}'
```

</RequestExample>

<ResponseExample>

```json
{
  "id": "wh_123",
  "url": "https://example.com/hooks/agent-chat",
  "secret": "whsec_...",
  "createdAt": "2026-10-13T00:00:00.000Z"
}
```

</ResponseExample>

<ResponseField name="secret" type="string" required>
  Shown once. The HMAC key is the base64 data after `whsec_`.
</ResponseField>

## Deliveries

Deliveries are HTTP `POST` with `Content-Type: application/json`.

| Header | Meaning |
| --- | --- |
| `webhook-id` | Stable id for this event and endpoint. A retry of the same event reuses it. |
| `webhook-timestamp` | Unix seconds used in the signature. |
| `webhook-signature` | `v1,` plus base64 HMAC-SHA256. |

The signed string is `{webhook-id}.{webhook-timestamp}.{raw body}`. Compare the raw body before parsing it. Reject a timestamp more than five minutes from now. Respond `2xx` quickly. A non-2xx response is retried up to 5 times.

```js
import { createHmac, timingSafeEqual } from "node:crypto";

function verify(secret, id, timestamp, rawBody, header) {
  const key = Buffer.from(secret.slice("whsec_".length), "base64");
  const digest = createHmac("sha256", key).update(`${id}.${timestamp}.${rawBody}`).digest("base64");
  const expected = Buffer.from(`v1,${digest}`);
  const provided = header.split(" ").find((part) => part.startsWith("v1,")) ?? "";
  const actual = Buffer.from(provided);
  return expected.length === actual.length && timingSafeEqual(expected, actual);
}
```

## Events

| Type | When |
| --- | --- |
| `agent.started` | A durable agent turn begins. `data.status` is `thinking`. |
| `agent.completed` | The assistant turn finished. |
| `agent.failed` | The turn failed or was cancelled. `data.status` says which. |
| `tool.completed` | A tool finished, including a failed tool. `data.status` is `completed` or `failed`. |

```json
{
  "id": "agent.completed:run_123",
  "type": "agent.completed",
  "createdAt": "2026-10-13T00:00:00.000Z",
  "data": {
    "chatId": "chat_123",
    "runId": "run_123",
    "messageId": "msg_assistant",
    "status": "completed",
    "routedModel": "openrouter/free"
  }
}
```

Fields named like keys, secrets, or tokens are removed before delivery. The Magica key is never included.

`DELETE /api/v1/webhooks/{webhookId}` stops further deliveries.
