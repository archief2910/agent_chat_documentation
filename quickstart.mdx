Send `Authorization: Bearer <credential>` on every route except `GET /api/health`, `GET /api/v1/config`, and `POST /api/v1/uploads/notify`.

The deployed API is `https://agent-chat-backend-production.up.railway.app`. A call with no credential returns:

```json
{
  "error": {
    "code": "UNAUTHENTICATED",
    "message": "Sign in to continue.",
    "retryable": false,
    "traceId": "687ac8e0-ca57-4af8-9ca7-7085acafd1e2"
  }
}
```

`traceId` is also the `x-request-id` header.

The host is the backend origin. There is no public API host yet, so use `http://localhost:3001` while the server runs on your machine.

## Clerk

Browser clients send the Clerk session token from `getToken()`. The API checks that the token's authorized party is the frontend origin.

## API keys

`POST /api/v1/api-keys` with a Clerk session returns a key once:

```json
{
  "id": "key_123",
  "name": "local",
  "prefix": "ak_a1b2c3d4e",
  "key": "ak_...",
  "createdAt": "2026-10-10T12:00:00.000Z"
}
```

Store `key`. Later calls show only `prefix`. `DELETE /api/v1/api-keys/{keyId}` revokes it. A revoked or unknown key gets the same `401` as a missing session.
